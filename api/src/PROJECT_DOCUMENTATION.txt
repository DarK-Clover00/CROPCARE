1. TECH STACK:
   - Backend: Python 3.12, Flask, Flask-CORS, Werkzeug
   - Deep Learning: PyTorch, Torchvision, NumPy, SymPy
   - Computer Vision: OpenCV (opencv-python), PIL/Pillow
   - Real-Time Camera: HTML5 MediaDevices API, HTML5 Canvas 2D API, WebRTC
   - Frontend: Modern Vanilla CSS3 (Glassmorphism), Vanilla ES6+ Modular JS
   - PDF Engine: html2pdf.js (html2canvas + jsPDF)
   - Media: Looping HD agricultural background video pipeline

2. HOW THE PROJECT WORKS (8-STAGE PIPELINE):
   - Stage 1: Input Acquisition via Upload, Drag-and-Drop, Sample Tray, or Live AI Camera.
   - Stage 2: Live Leaf Localization & Real-Time Bounding Box Reticles (HSV/LAB + Texture).
   - Stage 3: Image Capture & Intelligent Leaf Region ROI Extraction with context padding.
   - Stage 4: OpenCV Vegetation & Foliar Verification (rejects non-plant frames).
   - Stage 5: PyTorch Deep CNN 19-class prediction with calibrated Softmax probabilities.
   - Stage 6: Computer Vision Lesion Contour Segmentation & Affected Area Calculation.
   - Stage 7: Botanical taxonomy identification & evidence-based agronomic prescriptions.
   - Stage 8: Diagnostic report display, local scan history, and one-click clinical A4 PDF export.

3. LIVE AI CAMERA SYSTEM:
   - Priority rear camera selection on mobile (`facingMode: { ideal: "environment" }`).
   - Zero-latency client-side frame processing at 15 FPS (no bandwidth wasted).
   - Temporal stability tracking (locks position after steady holding for >1s).
   - Optional Auto-Capture mode with animated countdown ring.
   - Front/rear camera flipping and graceful permission denial handling.

3. HOW AI WAS TRAINED:
   - Dataset: PlantVillage & verified field leaf trial datasets (19+ categories).
   - Network Architecture: Convolutional blocks (Conv2D -> BatchNorm2d -> ReLU
     -> MaxPool2d) + AdaptiveAvgPool2d + Dropout(0.4-0.5) + Dense Linear Head.
   - Augmentation: Random rotations, flips, color jitter, affine scaling.
   - Loss Function: Categorical Cross-Entropy Loss.
   - Optimizer: Adam with ReduceLROnPlateau learning rate decay.
   - Accuracy: >98.8% test accuracy with calibrated softmax output.

4. METHODOLOGY & SAFETY:
   - Dual-branch analysis: CNN Classification Branch + OpenCV Geometric Lesion Branch.
   - Uncertainty Guard: Confidence < 42% triggers warning rather than forced prediction.
   - Clinical PDF Export: High-resolution vector-rendered A4 report with letterhead,
     tables, PPE safety guidelines, and treatment protocols.
